# Flag assets

SVG artwork from [Circle Flags](https://github.com/HatScripts/circle-flags),
revision `379588b5da95482d6bbf10bd45644a35b0609ea6`, under the adjacent MIT license.

Country flags and matching ISO subdivision flags are served locally.
Subdivision entries without artwork use a location icon. Currency flags identify
the issuing country when its ISO prefix matches a current tender country; the
euro uses the European Union flag. Shared calling codes use a globe.
